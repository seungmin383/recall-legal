seungmiiin은 Android 게임 Recall 100 Bullets(100 BULLETS : RECALL)를 운영합니다. 이 방침은 게임이 개인정보를 처리하는 방식과 이용자가 문의하거나 삭제를 요청하는 방법을 안내합니다.

## 1. 처리하는 정보와 이용 목적

| 기능 | 처리하는 정보 | 이용 목적 |
| --- | --- | --- |
| 게스트 플레이 | 게임 진행, 게임 내 재화, 해금 내역, 설정, 최근 플레이 기록, 게스트 식별자 | 기기에 진행과 설정 저장 |
| Google Play Games 로그인 | 플레이어 식별자와 표시 이름, 로그인 인증 코드와 토큰, Firebase 사용자 식별자 | 로그인 확인과 게임 계정 연결 |
| 클라우드 저장 | 게임 진행, 재화, 해금 내역, 설정, 게스트 식별자, 저장 갱신 시각 | 진행 백업과 기기 간 동기화 |
| 랭킹과 시즌 | 게임 계정 식별자, 표시 이름, 경기 식별자, 앱 버전, 캐릭터, 생존 시간, 처치 수, 경기 검증 기록, 순위, 시즌 보상과 수령 내역 | 경기 검증, 부정 이용 방지, 랭킹 표시, 보상 지급 |
| 문의와 개인정보 관련 요청 | 회신 이메일 주소, 메시지 내용, 이용자가 보낸 첨부 자료 | 문의 답변과 개인정보 관련 요청 처리 |

기본 게임은 게스트로 이용할 수 있습니다. Android에서 게임을 시작할 때 Google Play Games 인증이 시도될 수 있습니다. 게임 계정을 연결한 뒤 클라우드에 처음 저장하거나 저장된 진행을 불러오면 동기화가 시작됩니다. 동기화가 활성화된 동안 로비로 돌아올 때 변경된 진행이 자동으로 저장될 수 있습니다.

랭킹에 참여하면 게임 내 표시 이름, 캐릭터, 점수와 순위가 다른 로그인 이용자에게 표시될 수 있습니다.

## 2. 외부 서비스와 국외 처리

- **Google Play Games Services**는 로그인과 업적 기능을 제공합니다. SDK는 서비스 안정성과 개선을 위해 분석·진단 정보를 처리합니다. [Google Play Games 데이터 처리 안내](https://developer.android.com/games/pgs/data-collection)
- **Firebase Authentication**은 게임 계정을 인증합니다. Google은 미국에서 인증 정보를 처리하며, 보안과 부정 이용 방지를 위해 IP 주소와 브라우저·앱 정보도 처리합니다.
- **Firebase Realtime Database**는 싱가포르에 클라우드 저장과 랭킹 기록을 보관합니다. **Cloud Functions for Firebase**는 대한민국 서울에서 랭킹에 제출된 기록을 검증합니다. 관련 기능을 이용할 때 필요한 인증 정보와 게임 기록이 HTTPS로 전송됩니다. [Firebase 개인정보 및 보안 안내](https://firebase.google.com/support/privacy) · [Firebase 개인정보 보호 문의](https://firebase.google.com/support/privacy/dpo)
- **Unity Diagnostics**가 활성화된 빌드에서는 Unity가 앱의 충돌·오류 기록과 기기, 운영체제, 성능 정보를 안정성 진단에 사용할 수 있습니다. [Unity 개인정보처리방침](https://unity.com/legal/game-player-and-app-user-privacy-policy)
- **GitHub Pages**는 이 처리방침을 호스팅합니다. GitHub는 보안을 위해 페이지 방문자의 IP 주소를 기록합니다. [GitHub Pages의 데이터 처리 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)

클라우드 저장과 온라인 랭킹을 사용하지 않으려면 게임 계정 연결을 건너뛰고 게스트로 플레이할 수 있습니다.

## 3. 보유 기간과 파기

- **기기 내 게임 기록**은 Android 설정에서 앱 데이터를 지울 때까지 기기에 남습니다. 기기의 백업 설정에 따라 기록이 복원될 수 있습니다.
- **게임 계정과 클라우드 저장**은 계정을 이용하는 동안 보관하며, 계정 삭제가 완료되면 삭제합니다. Google은 삭제가 시작된 후 인증 기록을 운영 시스템과 백업에서 제거하는 데 최대 180일이 걸릴 수 있다고 안내합니다. Firebase Authentication에 기록된 IP 주소는 수 주 동안 보관됩니다.
- **랭킹·시즌 기록**은 지난 시즌 순위, 보상 수령 내역, 역대 최고 기록을 제공하기 위해 시즌 종료 후에도 필요한 기간 동안 보관합니다. 랭킹 기능 종료 등으로 보관 목적이 끝나면 파기합니다. 계정에 연결된 기록의 삭제는 아래 4번에서 요청할 수 있습니다.
- **문의 기록**은 문의에 답변하고 관련 요청을 처리할 때까지 보관하며, 처리가 끝나면 파기합니다.

보유 기간이 끝나거나 처리 목적이 달성되면 전자 기록을 복구하거나 재생하기 어려운 방법으로 파기합니다. 법령상 보존해야 하는 정보는 해당 법령이 정한 기간 동안 보관합니다.
